## Browsing the Marketplace {#browsing}

### Dashboard Overview

The Marketplace dashboard shows:

- **Marketplace Statistics:** Total public agents, average rating, total invocations, trending growth
- **Top Rated Agents:** Highest-rated agents from the community (when no filters applied)
- **Most Used Agents:** Most frequently invoked agents (when no filters applied)
- **Agent Grid:** All agents matching your filters

### Desktop vs Mobile

**Desktop:**
- Full filter toolbar (search, tags, sort)
- Three-column grid layout
- All controls visible

**Mobile:**
- Compact search bar
- Floating filter button (bottom-right)
- Single-column layout
- Tab-based filter drawer

## Searching and Filtering {#searching}

### Search by Name or Description

Type in the search box to find agents by:
- Agent name
- Description keywords
- Creator organization

**Example:** Search "customer" finds all customer-support-related agents.

### Filter by Tag

Select a tag to narrow results to specific categories:
- `support`: Customer service agents
- `sales`: Sales enablement agents
- `legal`: Legal document review agents
- `hr`: Human resources agents
- Custom tags from creators

### Sort Results

Choose how to order agents:

1. **Newest** (default): Recently published agents first
2. **Best Rated:** Highest average rating first
3. **Most Used:** Most invocations first

## Cloning Agents {#cloning}

### Why Clone?

Cloning copies a public agent into your workspace so you can:
- Customize it with your own Knowledge Units
- Adjust system prompts and model settings
- Keep the marketplace agent unchanged
- Test and iterate safely

### How to Clone

1. Find an agent in the marketplace
2. Click the **"Clone"** button on the agent card or detail page
3. Confirm - the agent is added to your workspace as a **Draft**

### After Cloning

The cloned agent:
- Starts as a **Draft** (not deployed)
- Has **no Knowledge Units** attached
- Retains the original name (with "clone" suffix)
- Belongs only to your organization
- Is **private** by default

**Next steps:**
- Add your own Knowledge Units to the agent
- Customize the system prompt
- Test in the chat
- Deploy when ready

## Rating and Reviewing {#rating}

### Leave a Rating

1. Open a public agent's detail page
2. Scroll to **"Your Rating"** section
3. Click the **stars** to set 1-5 rating
4. (Optional) Write a review in the text box
5. Click **"Save Rating"**

### What Makes a Good Review?

✅ **Do:**
- Share specific use cases ("Great for customer support emails")
- Mention performance ("Responds in under 2 seconds")
- Give constructive feedback ("Works well, but struggles with edge cases")
- Rate honestly based on your experience

❌ **Don't:**
- Give ratings without using the agent
- Post spam or promotional content
- Leave unrelated comments
- Use reviews for bug reports (contact support instead)

### Community Ratings

- Your rating is **anonymous** (only shows initials of username)
- All ratings are **public** and visible to others
- Ratings update the agent's **average score** instantly
- Community reviews help others find the best agents

## Publishing Your Own Agents {#publishing}

### Making an Agent Public

1. Go to **Agents** → select your agent
2. Click **"Visibility"** → **"Public"**
3. Confirm - your agent is now in the marketplace!

### Before Publishing

Ensure your agent:
- ✅ Is **deployed** (not draft)
- ✅ Has a **clear name** and description
- ✅ Has **relevant tags** (helps users find it)
- ✅ Works well with your **Knowledge Units**
- ✅ Has a **sensible system prompt**
- ✅ Uses a **reliable model** (Claude, GPT-4, etc.)

### Manage Your Public Agents

**View Settings:**
- Click your agent → **"Marketplace"** section
- See: rating, invocation count, clone count

**Change Visibility:**
- **Public** → visible in marketplace, anyone can clone
- **Unlisted** → hidden from marketplace, can still be accessed via direct link
- **Private** → only your organization

## Best Practices {#best-practices}

### For Discovering Agents

1. **Start with trending agents** - they're proven to work
2. **Read reviews** - real user feedback is valuable
3. **Check invocation count** - high usage = community trust
4. **Clone and test** - try before fully integrating
5. **Provide feedback** - leave ratings to help creators

### For Publishing Agents

1. **Start with a niche** - specialized agents rank better
2. **Use clear descriptions** - help users understand value
3. **Add relevant tags** - improves discoverability
4. **Monitor feedback** - respond to low ratings professionally
5. **Iterate based on usage** - refine based on invocation patterns

### For Collaborating

1. **Clone agents from your team** - leverage existing work
2. **Build on proven patterns** - don't reinvent
3. **Share successful agents** - publish high-quality work
4. **Rate each other** - constructive feedback improves quality
5. **Cross-pollinate ideas** - learn from different domains

## Troubleshooting

### I can't find an agent I'm looking for

- Try different search terms
- Remove filters (tags, sort)
- Check if it's in a featured collection
- Ask in the community Discord

### My cloned agent doesn't work properly

- Ensure you've added Knowledge Units
- Check the system prompt makes sense
- Test the agent chat first
- Review the original agent's reviews

### My published agent isn't getting invocations

- Improve your description and tags
- Ensure agent quality (test before publishing)
- Get user feedback via reviews
- Consider making it public if currently unlisted

### How do I unpublish an agent?

- Go to agent settings → **Visibility**
- Change from **Public** to **Unlisted** or **Private**
- Agent is immediately hidden from marketplace

## FAQ

**Q: Can I modify a cloned agent?**  
A: Yes! Cloned agents are yours to modify. The original remains unchanged.

**Q: Do I get notified when someone clones my agent?**  
A: Not yet, but clone count is visible on your agent's page.

**Q: Can I see who rated my agent?**  
A: Ratings are anonymous for privacy. You see ratings, not raters.

**Q: What if I publish a bad agent by mistake?**  
A: No problem - change visibility to **Unlisted** or **Private** instantly.

**Q: Are marketplace agents free to use?**  
A: Yes! All public agents can be cloned and used freely.

**Q: Can I commercialize a cloned agent?**  
A: Check the original creator's license terms. Most are open for commercial use.
